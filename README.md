# Red–Blue Policy Game

Participant-view demo of a 6-player team coordination game (4 Red, 2 Blue, 6 rounds).
Live page: https://rcalcott9.github.io/red-blue-policy-game/ — add `?team=red` or `?team=blue` to fix the team.

Demo only: other players' choices are scripted and no responses are recorded.
Built from `qualtrics_human_study/team_policy_game/mockup.html` (LLM_Coordination) by `build_deploy.py`.
